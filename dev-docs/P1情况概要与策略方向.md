## 三、剩余待商榷项（P1 尾部 + 原定 P2）

按拍板顺序排列；#1、#2、#3 已拍板执行（见"二、已完成"末三条）。

### 4. 服务层去 print（原项目计划放在 P2）
- `batch_processor.py` 有 23 处 print；`console.py` docstring 自己写着"服务层的 print 收敛属 P2 范围"。
- 选项：注入 reporter 回调（batch_processor 已用回调注入 prepare/ai，顺手）或按原计划留 P2。做的话输出行为会变化。

### 5. mypy 引入节奏
- 37% 函数无返回注解 + 存在错误注解，全量开启会被报错淹没。选项：先只 ruff 缓一缓 / 宽松配置 + per-module 白名单渐进 / 直接全量并接受一次性大修。

### 6. 存量 unittest 测试是否改写 pytest 风格
- pytest 能直接跑 unittest，改写收益一般。确定的做法是：新增测试用 pytest 惯用法、conftest 逐步建 fixtures；存量 14 个文件是否回头改看性价比。

### 7. macOS 快捷指令功能去留（产品决策）
- `BiliNote.shortcut` 打进 wheel 是刻意的（`shortcut.py` 按包路径运行时查找），不是误入库。真正的问题是：项目已跨平台后，`install-shortcut`/`shortcut-prompt-off` 这组 macOS 专属功能保不保留。保留则现状合理；不保留则文件、命令、wheel force-include 一起清。
