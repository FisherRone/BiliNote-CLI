# 输出设计
## 极简模式输出
只用于单个处理模式
激活方式：一个参数

```text
✓ 笔记生成成功！
标题：
原链接：
保存到: ~/.bilinote/output/notes/视频标题 - 作者 - BV1xx.md
```

## 批量处理输出调整
```text
从 JSON 加载全部 5 个视频链接          ← 仅 --json 时有这行
开始批量处理: 5 个任务 (AI 并发: 3)
使用模型: deepseek-chat

  ✓ 任务1 完成: <标题> - <id>
  ✗ 任务2 失败: <id> - <错误文本>
  ...（此处省略 3 个，实际要有）

============================================================
批量处理完成!
  成功: 3
  失败: 2
  总计: 5
输出目录: ~/.bilinote/output/notes/batch_20261001_153000
============================================================
```

## search 模式输出增强

search 模式是给 AI 用的，所以输出更丰富的信息会更有用。
**定义**：`结果行` 是单一搜索结果对应的文本
```text
搜索: 关键词  平台: bilibili
------------------------------------------------------------
搜索到 20 条结果：

1. <结果行>
2. <结果行>
...

搜索结果已保存至: ~/.bilinote/output/search_result/2026-10-01T15-30-00_关键词.json

使用 process 命令处理搜索结果：
  bilinote process --json "~/.bilinote/output/search_result/xxx.json"
  bilinote process --json "~/.bilinote/output/search_result/xxx.json" --index 1 2 3
```

### bilibili 的结果行格式
```text
<index>. up 主名称 - 视频标题  
发布时间：yyyy-mm-dd  播放量：3.4k  点赞量：120  收藏量：45  时长：7min
简介：
标签：xxx、xx
```
